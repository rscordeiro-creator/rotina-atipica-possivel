# Rotina Atípica Possível

Código da página de vendas publicada em https://rotina-atipica.rosangelacsdf.chatgpt.site.

Os arquivos da página ficam em `dist/`. Para visualizar localmente: `python3 -m http.server 8080 --directory dist`.

Esta cópia foi sincronizada com a versão publicada do Sites. Novas alterações no Sites precisam ser enviadas novamente para este repositório; a sincronização automática não está configurada.
